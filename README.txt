물음표 버전 2 — 간단한 사진 질문 게시판

실행: dist/index.html을 브라우저에서 열면 됩니다. 설치나 빌드가 필요 없습니다.
코드: dist/index.html 한 파일에 HTML, CSS, JavaScript를 담았습니다.

기능: 촬영/사진 첨부와 미리보기, 질문 도우미, 익명 질문/답변,
검색/과목/미답변/해결 필터, 해결 상태, 복습 저장, 질문 삭제.

사진은 긴 변 1400px 이하로 줄이고 JPEG로 다시 생성하여 저장합니다.
개인정보 자동 탐지/가림, 사진 자르기/그리기, 1:1 메시지,
학교 인증 및 실제 사용자 간 공유는 이 간단한 체험판에 포함하지 않았습니다.
질문과 사진은 브라우저 localStorage에만 저장됩니다.
브라우저 저장 공간이 부족하면 등록에 실패할 수 있으며 안내를 표시합니다.
